1콘텐츠 개요

핵심 구조: 부모님이 역사 이야기를 시작하면, 상상력이 풍부한 아이가 이야기에 빠져들고 화면이 아이의 상상 세계로 전환됩니다. 이야기가 끝날 즈음 다시 현실로 돌아오며 부모님의 설명도 마무리됩니다.

시청 대상

5~7세 미취학 아동과 함께 보는 부모

다루는 범위

한국사부터 시작하고, 소재가 떨어지면 세계사로 확장

영상 길이

10분 내외로 계획. 제작 부담이 크면 3분으로 축소 검토

업로드 주기

미정

등장인물

아이 캐릭터 1명, 부모님 캐릭터 (구성 미정)

제작 방식

단계마다 사람 담당자를 배정. 담당자는 사이트에 와서 앞 단계 자료를 받아 가고, 작업 결과를 올림

10분 vs 3분 참고: 글 작업(기획, 시나리오, 검수)은 길이가 늘어도 부담이 크지 않습니다. 병목은 콘티와 영상 컷 제작입니다. 컷 하나가 보통 5~10초이므로 10분 영상은 약 60~120컷, 3분 영상은 약 20~35컷입니다. 해당 담당자의 작업량도 거의 이 비율대로 늘어납니다.

2누가 쓰는가

총괄 PD 1명 (나)

  • 에피소드를 만들고 단계별 담당자를 배정함
  • 핵심 4단계에서 결과물을 승인하거나 반려함
  • 담당자별 작업량과 마감을 보고 역할을 다시 나눔

단계 담당자 (사람)

  • 자기에게 배정된 작업만 내 작업함에서 확인
  • 앞 단계 결과물을 보거나 내려받아 작업
  • 정해진 양식에 맞춰 결과를 작성·업로드하고 제출
  • 다른 단계 결과물의 검수자로도 배정됨
  • 한 사람이 여러 역할을 겸할 수 있음
이번 수업은 1인 시연입니다. 기능 구현과 디자인이 목표이므로, 실제로는 한 사람이 화면 상단의 "나는 누구?" 선택으로 PD와 담당자 A~E를 바꿔가며 흐름을 보여줍니다. 계정·비밀번호 없이 이름만 고르면 그 사람의 화면이 됩니다.
담당자가 개인적으로 AI 도구를 쓰는 것은 자유입니다. 사이트는 "누가 무엇을 받아서 무엇을 냈는가"만 관리하고, 작업 방법은 묻지 않습니다. 사이트가 AI와 직접 연결되는 것은 다음 수업 범위입니다.

3담당자 작업 흐름

한 단계가 다음 단계로 넘어가는 과정입니다. 모든 단계가 같은 흐름을 따릅니다.

새 작업 표시앞 단계가 끝나면 내 작업함에 새 작업과 "새 작업 N건" 배지가 뜸
자료 받기앞 단계 결과물, 설정집, PD 지시사항 확인·다운로드
작업사이트 밖에서 자유롭게 작업 (직접 또는 개인 AI 도구)
제출양식 작성 + 파일(이미지·음성·영상)을 사이트에 직접 업로드
검수배정된 검수자가 지적 사항을 남김 → 필요시 수정 후 재제출
승인·전달승인 단계면 PD 승인 후, 아니면 검수 통과 후 다음 담당자에게 넘어감

5보고 나서 무엇을 하는가

총괄 PD

  • 승인 / 반려: 핵심 4단계 결과물 확인 후 다음 단계로 보내거나 수정 요청
  • 배정 변경: 작업량을 보고 담당자를 바꾸거나 추가
  • 재작업 요청: 특정 단계만 다시 하도록 되돌림. 이전 버전과 비교
  • 지연 대응: 마감이 지난 작업 알림을 보고 독촉하거나 재배정

단계 담당자

  • 자료 받기: 앞 단계 결과물과 설정집 확인·다운로드
  • 제출: 양식 작성, 파일 직접 업로드
  • 검수: 배정된 결과물에 지적 사항 남기기
  • 수정 재제출: 반려·지적 사항 반영 후 새 버전 제출

6제작 단계와 승인 지점

모든 단계는 제출 후 다른 담당자가 검수합니다. 기본 검수자는 다음 단계 담당자이고, PD가 여유 있는 사람으로 바꿀 수 있습니다. 승인 표시가 있는 4단계는 검수 뒤 PD가 직접 승인해야 다음으로 넘어갑니다.

※ 지금은 핵심 단계만 승인(B안)하고, 흐름이 자리를 잡으면 최종 영상만 확인(C안)하도록 설정에서 바꿀 수 있게 만듭니다.

1
스토리 컨셉 승인주제 선정, 핵심 교훈, 상상 세계 콘셉트

7역할 분담과 주고받는 자료

각 역할이 무엇을 받고 무엇을 내는지를 고정해 둡니다. 담당자 A~E는 1인 시연용 가상 인물이며, "나는 누구?" 목록에 그대로 나옵니다. 마지막 칸은 다음 수업에서 AI로 바꿀 때의 후보입니다.

8AI 전환을 위한 설계 원칙

다음 수업에서 사이트를 갈아엎지 않고 담당자만 바꿔 끼우려면, 지금부터 아래 네 가지를 지켜서 만듭니다.

① 담당자에 "종류" 칸을 둔다

담당자 정보에 사람 / AI 구분을 미리 넣어 둡니다. 지금은 모두 "사람"이고, 나중엔 같은 자리에 AI를 등록하면 됩니다.

② 제출 양식을 항목으로 고정한다

자유 글 한 덩어리가 아니라 7장의 "내는 것"처럼 정해진 칸으로 받습니다. 사람이 채우던 칸을 나중에 AI가 같은 형식으로 채우게 됩니다.

③ 단계 사이는 "제출 → 다음 작업 생성"으로만 잇는다

앞 단계가 승인되면 다음 담당자의 작업함에 작업이 생기는 한 가지 방식만 씁니다. 받는 쪽이 사람이든 AI든 같은 통로를 씁니다.

④ 받는 자료를 단계마다 명시한다

각 단계가 어떤 앞 단계 결과물을 읽는지 정해 둡니다. 나중에 AI에게 넘길 입력(프롬프트 재료)이 그대로 이것이 됩니다.
